## Installation

1. Download the latest mode files:

   [**Download GTA IV Mode Files**](https://github.com/IAVARABBASOV/gta4-modes/releases/download/gta4mode/GTA.IV.Mode.Files.7z)

2. Extract the downloaded `.7z` archive using **7-Zip** or another compatible archive manager.

3. Copy the extracted files into your **GTA IV game directory**.

   The folder should contain `GTAIV.exe`.

4. If Windows asks whether you want to replace existing files, choose **Replace the files in the destination**.

5. Launch GTA IV and enjoy the mode.

### Requirements

* GTA IV **The Complete Edition**
* **7-Zip** or another `.7z` archive extractor
