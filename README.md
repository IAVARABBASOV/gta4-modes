## Installation

1. Download the latest mode files:

   [**Download GTA IV Mode Files**](https://github.com/IAVARABBASOV/gta4-modes/releases/download/gta4mode/GTA.IV.Mode.Files.7z)

2. Extract the downloaded `.7z` archive using **7-Zip** or another compatible archive manager.

3. Copy the extracted files into your **GTA IV game directory**.

   The folder should contain `GTAIV.exe`.

4. If Windows asks whether you want to replace existing files, choose **Replace the files in the destination**.

5. Launch GTA IV and enjoy the modes.

### Requirements

- GTA IV **The Complete Edition**
- **7-Zip** or another `.7z` archive extractor

# Included Modes

## 🚖 Any Taxi

Turn any NPC vehicle into a taxi and let the driver take you to your waypoint.

### Controls

| Key | Action |
|------|--------|
| **N** | Enter the nearest NPC vehicle as a passenger and begin taxi mode |
| **N** | Change destination while driving |
| **N** | Cancel taxi mode |
| **M** | Toggle fast-forward while the taxi is driving |

Features

- Drive to the current map waypoint
- Automatic NPC driver
- Time acceleration while travelling
- Collision protection during the ride

---

## 🛡️ Bodyguards

Spawn friendly bodyguards that fight alongside you.

### Controls

| Key | Action |
|------|--------|
| **Insert** | Spawn a bodyguard (up to 5 total) |
| **Delete** | Remove all bodyguards |

Features

- Friendly AI companions
- Uses your currently equipped weapon
- High ammunition
- Automatically joins your group

---

## 🚙 Convoy

Spawn an armed escort vehicle that follows and protects you.

### Controls

| Key | Action |
|------|--------|
| **F8** | Spawn convoy |
| **F9** | Remove convoy |
| **F1** | Toggle combat mode |
| **R** | Repair convoy vehicle |
| **F12** | Unlock all islands |

### Console Commands

```text
convoy [VehicleModel]
convoyend
```

Features

- Four armed escorts
- AI driver follows the player
- Combat mode for passengers
- Supports custom vehicle models

---

## 🚗 Vehicle Browser

Browse and spawn any GTA IV vehicle through an in-game menu.

### Controls

| Key | Action |
|------|--------|
| **F6** | Open/close Vehicle Browser |

### Console Commands

```text
vb
sv <VehicleModel>
lv [Category]
```

Features

- Browse vehicles by category
- Spawn vehicles
- Replace current vehicle
- Random colors
- Spawn invincible vehicles

---

## 🔧 Vehicle Controls

Vehicle utility window with quick controls.

### Controls

| Key | Action |
|------|--------|
| **F7** | Open Vehicle Controls window |
| **Z** | Toggle indicator lights |
| **X** | Toggle hazard lights |
| **R** | Repair current vehicle |

Window Features

- Hood control
- Trunk control
- Open/close all passenger doors
- Indicator lights
- Hazard lights

---

## 🎨 Vehicle Editor

Customize your current vehicle.

### Console Command

```text
EditCar
```

Features

- Change primary color
- Change specular color
- Change feature colors
- Lock/unlock doors
- Open or close every door individually
